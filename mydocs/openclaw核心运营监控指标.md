# openclaw核心运营监控指标体系

### 1.1 Token用量监控

| **指标类别** | **具体指标** | **数据来源** | 拟优先级 |
| --- | --- | --- | --- |
| **模型Token消耗** | 总消耗量、Input消耗量、Output消耗量 | Session Logs (`usage.input/output`) | 高 |
| **OpenClaw Token** | 总消耗量、Input消耗量、Output消耗量、缓存读写消耗量`cache_read`/`cache_write` | Session Logs (`usage.cacheRead/write`) | 高 |
| **分小时监控** | 小时级Token消耗波峰波谷、趋势分析 | Session Logs（按小时聚合） | 高 |
| 消息统计 | 累计消息总数，包含用户发送量、AI回复量 | Session Logs  | 高 |

### 1.2 性能监控

| **指标类别** | **具体指标** | **数据来源** | 拟优先级 |
| --- | --- | --- | --- |
| 响应耗时 | AI回复的平均耗时 (Avg)、最小值 (Min) 及最大值 (Max) |  | 中 |
| **错误率** | 总错误率（`errors/total`）、按错误类型分布 | Session Logs (`errors`字段) | 中 |
| **错误详情** | 错误堆栈、失败原因分析、错误发生时间 | Session Logs (`error`字段) | 低 |
| **P95/P99延迟** | 错误相关操作的延迟分布（如工具调用失败耗时） | Session Logs (`durationMs`) | 低 |

### 1.3 内容监控与违规风险

| **指标类别** | **具体指标** | **数据来源** | 拟优先级 |
| --- | --- | --- | --- |
| **内容监控记录** | 用户提问内容、最终回答结果、会话上下文 | Session Logs (`message.content`) | 低 |
| **违规风险** | 敏感词命中、恶意内容标记、合规检查结果 | 内容审核引擎 | 低 |
| **IP地址** | 用户请求IP、实例所在IP | Gateway API (`client_ip`扩展字段) | 低 |

### 1.4 使用人监控

| **指标类别** | **具体指标** | **数据来源** | 拟优先级 |
| --- | --- | --- | --- |
| **用户身份** | 用户ID、用户名、所属部门/团队 | Session Logs (`user_id`字段) | 高 |
| **使用行为** | 个人会话数、消息量、Token消耗、成本、常用工具排行 | Session Logs（按用户聚合） | 高 |
| **用户活跃度** | 日/周/月活跃用户数 | Session Logs（按用户+时间聚合） | 中 |

### 1.5 会话监控与调用链

| **指标类别** | **具体指标** | **数据来源** | 拟优先级 |
| --- | --- | --- | --- |
| **会话基础信息** | 会话ID、开始/结束时间、参与用户、关联实例/渠道 | Session Logs (`session_id`/`timestamp`) | 高 |
| **调用链记录** | 每个问题的工具/技能调用顺序、输入输出、依赖关系 | Session Logs (`tool_use`/`tool_result`) | 中 |
| **执行结果** | 执行是否成功、各阶段耗时（如工具调用/模型推理）、总耗时 | Session Logs (`durationMs`/`is_error`) | 中 |
| **命令执行** | 执行的系统命令、脚本内容、执行结果（成功/失败） | Session Logs（扩展`tool_use`字段） | 低 |

### 1.6 工具与技能监控

| **指标类别** | **具体指标** | **数据来源** | 拟优先级 |
| --- | --- | --- | --- |
| **工具调用** | 调用次数、成功率、平均耗时、P95/P99耗时、错误类型分布 | Session Logs (`toolNames`/`is_error`) | 高 |
| **技能使用** | 技能调用排行、耗时分布、成本占比、关联会话数 | Session Logs（`skill_name`聚合） | 高 |
| **技能效果** | 技能返回结果质量（如准确率）、用户反馈（需新增） | 扩展Session Logs（`feedback`字段） | 高 |

### 1.7 系统与资源监控

| **指标类别** | **具体指标** | **数据来源** | 拟优先级 |
| --- | --- | --- | --- |
| 实例健康 | 实例在线状态 (ok/unhealthy)、系统运行时长 (Uptime) 及整体可用率 | k8s集群 | 高 |
| 系统负载 | 监控pod节点的 CPU 使用率、内存占用及磁盘使用量 | Prometheus | 中 |
| 连接状态 | 监控活跃会话数、Agent 心跳状态 | k8s集群 | 高 |
